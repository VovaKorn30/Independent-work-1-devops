# Independent-work-1-devops

## Самостійну роботу виконав студент групи ПДМ-51 Корнєєв Володимир

Цей проєкт містить базові вправи з Python для роботи з рядками та генератором.

### Частина 1. Базові вправи
- Функція, яка приймає рядок і виводить його у консоль  
- Функція, яка визначає регістр букв у рядку (всі великі, всі малі або змішані)  
- Формування списку літер слова `"smogtether"` у верхньому регістрі  
- Генератор, який поперемінно повертає `"Парне"` та `"Непарне"`

### Частина 2. Робота з модулями
- Модуль для функцій роботи з рядками  
- Модуль для генератора  
- Модуль з прикладами запуску, що демонструє роботу функцій та генератора

## Independent work was performed by a student of the PDM-51 group, Kornieiev Volodymyr.

This project contains basic Python exercises for working with strings and a generator.

### Part 1. Basic exercises
- Function that takes a string and prints it to the console  
- Function that checks the case of letters in a string (all uppercase, all lowercase, or mixed)  
- Creating a list of letters of the word `"smogtether"` in uppercase  
- Generator that alternately returns `"Even"` and `"Odd"` (Ukrainian: "Парне"/"Непарне")

### Part 2. Working with modules
- Module for string-related functions  
- Module for the generator  
- Module with example usage demonstrating the functions and generator
